This  provides a clear and practical guide to **Power over Ethernet (PoE)** standards and **fiber optic power budgets**. It explains how PoE delivers power alongside data, the different PoE standards, how to match transceivers, and how to calculate whether a fiber link will have enough optical power to operate reliably.



---

### Power over Ethernet (PoE) and Fiber Power Budgets Cheat Sheet

This guide covers PoE sources, standards, compatibility, and fiber optic power calculations.

---

#### Power over Ethernet (PoE) Basics

| Aspect | Description |
| :--- | :--- |
| **What It Does** | Delivers DC power over the same Ethernet cable (twisted pair) that carries data. |
| **Benefit** | Single cable for data + power – simplifies installation for phones, access points, cameras, etc. |
| **Power Sources** | - **Endspan:** PoE‑capable switch (most common). <br> - **Midspan:** Inline power injector (used with non‑PoE switches). |

---

#### PoE Standards

| Standard | Common Name | Max Power (at device) | Max Current | Typical Use |
| :--- | :--- | :--- | :--- | :--- |
| **IEEE 802.3af** | PoE | 15.4 W | 350 mA | VoIP phones, small APs, basic fixed cameras. |
| **IEEE 802.3at** | PoE+ | 25.5 W | 600 mA | Larger phones, pan‑tilt‑zoom (PTZ) cameras, videophones. |
| **IEEE 802.3bt Type 3** | PoE++ (4‑pair) | 51 W | 600 mA | Laptops, large APs, industrial devices. |
| **IEEE 802.3bt Type 4** | PoE++ (high power) | 71.3 W | 960 mA | Large PTZ cameras, thin clients, building automation. |

**Key Points:**
- PoE++ supports higher Ethernet speeds: 2.5GBASE‑T, 5GBASE‑T, 10GBASE‑T.
- Higher‑power standards are **backward compatible** (a PoE+ switch can power a PoE device, but not the reverse).
- A PoE+ switch **cannot** power a PoE++ device fully (insufficient power budget).

---

#### PoE Compatibility and Capacity

| Rule | Explanation |
| :--- | :--- |
| **Device needs equal or lower standard** | A PoE++ switch can power PoE or PoE+ devices; a PoE+ switch cannot power a PoE++ device (won't provide enough power). |
| **Check switch labelling** | Switches often label ports with PoE capability (AF / AT / BT). |
| **Total power budget matters** | Switch has a maximum total PoE power (e.g., 200 W, 720 W). Sum the **maximum draw** of all connected devices; ensure it is ≤ switch capacity. |

**Example:** If a switch supports 200 W total PoE, you cannot connect ten 25.5 W PoE+ devices (255 W > 200 W). Some devices will fail to power up.

---

#### Fiber Optic Transceivers (SFPs)

| Aspect | Description |
| :--- | :--- |
| **Matching requirement** | Transceiver must match the fiber type (multimode vs. single‑mode) and wavelength (e.g., 850 nm, 1310 nm). |
| **Wavelength markings** | Printed on the transceiver (often in very small text). |
| **Risk** | Using mismatched transceivers (e.g., 850 nm on one end, 1310 nm on the other) causes signal loss, errors, or complete link failure. |

**Best Practice:** Document your transceivers and verify compatibility before installation. Once plugged in, the label may not be visible – you may need to remove the transceiver to read it.

---

#### Fiber Optic Power Budget Calculation

To ensure a reliable link, the **received power** must be **stronger than the receiver's sensitivity**.

| Term | Description | Typical Unit |
| :--- | :--- | :--- |
| **Transmit power (Tx)** | Optical power launched into the fiber by the transmitter. | dBm (decibels relative to 1 milliwatt) |
| **Receiver sensitivity (Rx)** | Minimum optical power the receiver needs to interpret the signal correctly (usually a **negative** dBm value). | dBm (e.g., –17 dBm) |
| **Link loss** | Total power lost across the fiber, connectors, and splices. | dB |
| **Received power** | Power arriving at the receiver = Transmit power – Link loss. | dBm |

**Power Budget Formula:**

`Received Power (dBm) = Transmit Power (dBm) – Link Loss (dB)`

**Link Loss Includes:**
- **Fiber attenuation** (loss per kilometer – depends on wavelength and fiber type).
- **Connector losses** (each connector adds ~0.5–1.5 dB).
- **Splice losses** (if fusion or mechanical splices are used).

**Acceptability Rule:**

`Received Power ≥ Receiver Sensitivity`  (e.g., –16 dBm ≥ –17 dBm → good)

`Received Power < Receiver Sensitivity` (e.g., –20 dBm < –17 dBm → insufficient signal → errors or no link)

---

#### Power Budget Example

| Parameter | Value |
| :--- | :--- |
| Transmit power (SFP, 850 nm) | –3 dBm |
| Fiber length | 500 m of multimode (attenuation 3 dB/km = 1.5 dB loss) |
| Connectors | 4 connectors (0.75 dB each = 3 dB total) |
| Splices | 0 (none) |
| **Total Link Loss** | 1.5 dB + 3 dB = **4.5 dB** |
| **Received Power** | –3 dBm – 4.5 dB = **–7.5 dBm** |
| Receiver sensitivity (example) | –17 dBm |
| **Result** | –7.5 dBm ≥ –17 dBm → **Link is good.** |

**If link loss were higher (e.g., 15 dB):** Received power = –18 dBm, which is less than –17 dBm → **insufficient signal** → errors or no link.

#### Common Problems and Solutions

| Problem | Possible Cause | Solution |
| :--- | :--- | :--- |
| PoE device not powering up | Insufficient switch PoE budget; mismatched standard. | Check total wattage; upgrade switch or use external injector. |
| PoE device reboots intermittently | Power draw exceeds available budget during peaks. | Re‑calculate budget; reduce load or upgrade power supply. |
| Fiber link has high error counts | Mismatched transceivers (wavelength or fiber type). | Verify transceiver markings; replace with matching pair. |
| Fiber link works but low light | Dirty connectors, bend radius violation, too many splices. | Inspect/clean connectors; reroute cable; reduce splices. |

---

#### Key Takeaways

| Takeaway | Explanation |
| :--- | :--- |
| **PoE saves cabling** | Data and power over one cable; ideal for phones, APs, cameras. |
| **PoE standards are different** | PoE (15.4 W), PoE+ (25.5 W), PoE++ (51–71 W). |
| **Backward compatible, but not forward** | Higher power switch works with lower power device; lower power switch cannot fully power higher power device. |
| **Total power budget matters** | Add up all device power draws; must be ≤ switch PoE capacity. |
| **Fiber transceivers must match** | Wavelength and fiber type (MMF / SMF) must be identical on both ends. |
| **Power budget = Tx power – link loss** | Received power must be ≥ receiver sensitivity (usually negative dBm). |
| **Negative dBm values get smaller** | –10 dBm is stronger than –20 dBm. |
