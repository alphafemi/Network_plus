This  provides a comprehensive guide to **wireless network troubleshooting and optimisation**. It covers channel selection, interference management, signal strength (attenuation), client roaming, and common attacks like deauthentication/disassociation.



---

### Wireless Network Troubleshooting Cheat Sheet

This guide covers best practices for channel selection, interference avoidance, signal optimisation, client roaming, and wireless attack mitigation.

---

#### Frequency Bands and Channel Selection

| Band | Non‑Overlapping Channels (e.g., US) | Interference Risk | Notes |
| :--- | :--- | :--- | :--- |
| **2.4 GHz** | 3 (channels 1, 6, 11) | High (crowded, overlapping) | Many non‑Wi‑Fi devices also use this band (Bluetooth, microwaves). |
| **5 GHz** | Many more (e.g., 36, 40, 44, 48, 149–165) | Lower | Less crowded than 2.4 GHz. |
| **6 GHz** (Wi‑Fi 6E/7) | Very wide (many non‑overlapping channels) | Lowest (new, less congested) | Requires Wi‑Fi 6E or 7 devices. |

**Channel Overlap Problem (Example):**

| Good Practice | Poor Practice |
| :--- | :--- |
| Use channels 1, 6, 11 (non‑overlapping in 2.4 GHz). | Using channel 8 overlaps with both channel 6 and channel 11, causing interference for all. |

**Recommendations:**
- Prefer **5 GHz** or **6 GHz** over 2.4 GHz when possible.
- Use **auto‑channel selection** (many modern APs dynamically pick the best channel).
- If using manual channels, periodically re‑evaluate (neighbouring networks change over time).

---

#### Mitigating Interference

| Interference Source | Mitigation |
| :--- | :--- |
| **Other access points (co‑channel / adjacent channel)** | Reduce transmit power; use non‑overlapping channels; auto‑channel selection. |
| **Non‑Wi‑Fi devices** (microwaves, Bluetooth, cordless phones) | Move AP away; use 5 GHz or 6 GHz. |
| **Overlapping coverage from own APs** | Reduce transmit power (cells should overlap gently, not too much). |

**Best Practice:** Rather than one high‑power AP, use **multiple lower‑power APs** on different channels to provide better coverage with less interference.

---

#### Signal Strength and Coverage (Attenuation)

| Term | Description |
| :--- | :--- |
| **Attenuation** | Signal loss over distance (air, walls, floors). |
| **Heat map / site survey** | Visual representation of signal strength across an area (hot colours = strong, cool colours = weak). |

**Ways to Improve Signal / Coverage:**

| Method | Notes |
| :--- | :--- |
| **Increase AP transmit power** | Not all APs support this; may increase interference to neighbours. |
| **Add external antenna** | Provides gain (focuses energy). |
| **Use low‑loss coax** | Coaxial cable loses signal, especially at higher frequencies; keep cable runs short. |
| **Add more APs (lower power each)** | Best practice for large areas. |

**Tools:** Wi‑Fi analyser (walk‑around site survey), heat mapping software.

---

#### Client Roaming and Configuration Consistency

| Requirement | Explanation |
| :--- | :--- |
| **Same SSID** (network name) on all APs | Allows clients to roam without re‑selecting network. |
| **Same security settings** (WPA2/WPA3, passphrase) | Mismatched credentials cause authentication failure. |
| **Same VLAN / subnet** (for seamless roaming) | Otherwise IP address changes may disrupt connections. |

**If Roaming Fails (client dropped when moving between APs):**
- Check for mismatched SSID, security, or VLAN configuration.
- Verify coverage overlap (too little overlap → client loses signal before finding next AP).
- Ensure APs are on the same controller (or use a consistent roaming protocol like 802.11r).

---

#### Legacy/Low‑Speed Device Support

| Option | Effect |
| :--- | :--- |
| **Enable legacy support** (e.g., 802.11b rates) | Slower speeds bring down overall network efficiency (airtime consumed by slow devices). |
| **Disable legacy support** (allow only newer standards) | Better throughput if all clients support newer standards (802.11n, ac, ax, be). |

**Recommendation:** If all clients support modern standards, disable legacy/low‑speed rates in the AP configuration.

---

#### Wireless Attacks: Deauthentication / Disassociation

| Attack | Description | Impact |
| :--- | :--- | :--- |
| **Deauthentication frame attack** | Attacker sends forged deauth frames (as if from AP) to a client. | Client disconnects; may reconnect but attacker repeats. |
| **Disassociation frame attack** | Similar to deauth; forces client to leave the network. | DoS (client cannot stay connected). |

**Why It Works:** Older 802.11 management frames (deauth, disassoc) are **unprotected** (no encryption, no authentication). The client cannot distinguish a real frame from a fake one.

**Detection:**
- Capture 802.11 frames with a Wi‑Fi adapter in monitor mode (Wireshark, tcpdump).
- Look for excessive deauth/disassoc frames from a specific source.

**Mitigation:**
- Use **802.11w** (Protected Management Frames) – available in 802.11ac and newer standards.
- Upgrade to modern APs and clients that support management frame protection.

#### Wireless Troubleshooting Summary

| Problem | Likely Cause | Diagnostic Tool / Action |
| :--- | :--- | :--- |
| Low throughput, high retries | Interference, overlapping channels | Wi‑Fi analyser; change channel or move to 5/6 GHz. |
| Client cannot roam | Inconsistent SSID/security/VLAN across APs | Check AP configurations; ensure they match. |
| Intermittent disconnection | Deauth/disassociation attack (or interference) | Packet capture (802.11 monitor) to see deauth frames. |
| Weak signal in certain area | Attenuation, distance, obstacles | Site survey (heat map); add AP or external antenna. |
| Co‑channel interference (CCA busy) | Too many APs on same channel | Reduce power; spread APs across non‑overlapping channels. |

---

#### Key Takeaways

| Takeaway | Explanation |
| :--- | :--- |
| **Use non‑overlapping channels** | In 2.4 GHz: channels 1, 6, 11 (North America). Prefer 5/6 GHz. |
| **Auto‑channel assignment helps** | APs can detect interference and move to a clearer channel. |
| **More (lower power) APs are better** | Uses different channels, reducing contention and interference. |
| **Signal weak? Check antennas, power, and obstacles** | Heat maps help visualise coverage. |
| **Roaming requires identical SSID + security** | Mismatched configurations break seamless roaming. |
| **Disable legacy rates for best throughput** | Avoid dragging down the whole network with slow devices. |
| **Deauth attacks are a known Wi‑Fi vulnerability** | Upgrade to 802.11w (Protected Management Frames) to prevent. |
