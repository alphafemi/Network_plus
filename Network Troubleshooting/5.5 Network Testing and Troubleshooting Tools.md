This  provides a practical guide to essential **physical layer testing and troubleshooting tools** used by network administrators. It covers tools for tracing cables (tone generator/probe), verifying continuity (cable tester), capturing traffic (network tap, port mirroring), analyzing wireless networks (Wi‑Fi analyzer, spectrum analyzer), and finding fiber breaks (visual fault locator).


---

### Network Testing and Troubleshooting Tools Cheat Sheet

This guide covers the most common tools for physical and link‑layer diagnosis, traffic capture, and wireless analysis.

---

#### Cable Tracing and Identification

| Tool | Function | How It Works |
| :--- | :--- | :--- |
| **Tone generator** (fox) | Sends an analog tone onto a copper cable (twisted pair, coax, or individual wires). | Connects via modular jack, alligator clips, or punchdown block. |
| **Inductive probe** (hound) | Detects the tone emitted by the paired tone generator. | Only needs to be near the cable (does not require electrical contact). |

**Use Case:** Locating a single cable in a large bundle, ceiling drop, or patch panel without disturbing other cables.

**Combined device:** Many tools combine both functions (tone generator on one end, probe on the other).

---

#### Cable Tester (Continuity Tester)

| Aspect | Description |
| :--- | :--- |
| **What it tests** | Continuity (pin‑to‑pin wiring) – which pins are connected, shorted, crossed, or open. |
| **What it does NOT test** | Bandwidth, category compliance (Cat5e/6/6a), attenuation, crosstalk. |
| **Typical output** | Sequential LED lights (1‑8) showing successful connection; a missing light indicates an open pin; mis‑ordering indicates a cross. |

**Use Cases:**
- Verify that a newly terminated cable is wired correctly (T568A or T568B).
- Identify broken pairs, shorts, or crossed wires after punching down or crimping.

**Note:** Many tone‑generator/probe kits also include a continuity test mode (plug both ends into the two devices to verify all 8 pins).

#### Network Tap and Port Mirroring (Traffic Capture)

| Method | Description | Requires Power? | When to Use |
| :--- | :--- | :--- | :--- |
| **Physical tap** | A physical device inserted into the link (breaks the connection). Splits the signal to a monitor port. | Passive (fiber) – no power needed; <br> Active (copper) – may need power to regenerate signal. | High‑bandwidth links; when you need a perfect copy without switch buffering. |
| **Port mirror (SPAN)** | Switch copies traffic from one or more ports to a designated monitor port. | No (switch powered). | Convenient; no physical cabling change; but subject to switch buffering and oversubscription. |

**SPAN (Switched Port Analyzer):**
- Destination port receives a copy of traffic from one or more source ports.
- Risk: If the total mirrored bandwidth exceeds the destination port speed, packets may be dropped.

**Example (Mirroring 2×1 Gbps → 1 Gbps monitor):**  
2 Gbps of traffic cannot fit into a 1 Gbps monitor port → packet loss.

**Tap advantage:** No buffer loss; provides full bidirectional copy.

#### Wireless Survey and Analysis Tools

| Tool | Purpose | Output |
| :--- | :--- | :--- |
| **Wireless survey tool** | Measure coverage, signal strength, interference. | Heat maps, channel utilisation, overlapping BSSIDs. |
| **Wi‑Fi analyzer** | Capture and decode 802.11 frames; list access points (SSID, BSSID, channel, security, RSSI). | Channel usage chart; list of nearby APs; client association information. |
| **Spectrum analyzer** | View all RF energy across a frequency range (2.4 GHz, 5 GHz, 6 GHz), including non‑Wi‑Fi sources. | Visualisation of interference (microwave ovens, Bluetooth, cordless phones, radar). |

**Signal‑to‑Noise Ratio (SNR) Visualisation (from video):**
- **Low SNR:** Signal and noise are close → poor performance, low throughput.
- **High SNR:** Signal much stronger than noise → good performance.

**When to use a spectrum analyzer:**
- Suspected non‑Wi‑Fi interference (microwave, wireless camera, radar).
- Wi‑Fi analyser shows high channel utilisation but no other APs.

---

#### Visual Fault Locator (Fiber Optic)

| Aspect | Description |
| :--- | :--- |
| **How it works** | A visible red laser (or bright LED) injected into the fiber core. |
| **What it finds** | Breaks, cracks, sharp bends, bad splices – light leaks out at the fault point, making it visible. |
| **Procedure** | Connect to one end of the fiber; view along the cable (may need darkened room). |
| **Limitation** | Cannot measure loss or exact distance; only finds major faults. |

**Use Cases:**
- Quick check of a patch cord before installation.
- Locating a visible bend or crack in an installed cable plant.

#### Tool Summary Table

| Tool | Use Case | Layer |
| :--- | :--- | :--- |
| **Tone generator + inductive probe** | Locate a specific cable in a bundle | Physical (L1) |
| **Cable tester (continuity)** | Verify pin‑to‑pin wiring, detect opens/shorts/crosses | Physical (L1) |
| **Network tap** | Capture full‑bandwidth traffic without loss | Physical / Data Link (L1/L2) |
| **Port mirror (SPAN)** | Capture traffic using the switch (convenient, potential loss) | Data Link (L2) |
| **Wi‑Fi analyzer** | Survey wireless coverage, list APs, channel usage | Data Link (L2) |
| **Spectrum analyzer** | Detect non‑Wi‑Fi RF interference | Physical (L1 RF) |
| **Visual fault locator** | Locate fiber breaks and sharp bends | Physical (L1) |

---

#### Key Takeaways

| Takeaway | Explanation |
| :--- | :--- |
| **Tone + probe finds cables non‑invasively** | The inductive probe only needs to be near the cable – no direct contact. |
| **Cable tester verifies wiring** | Essential after punching down or crimping; shows opens, shorts, crosses. |
| **Port mirror (SPAN) is convenient but has limits** | Total mirrored traffic cannot exceed monitor port speed. |
| **Physical taps are lossless** | Best for high‑throughput links (10 Gbps+). |
| **Wi‑Fi analyser shows 802.11 network health** | Lists APs, channels, SNR, but cannot see non‑Wi‑Fi interferers. |
| **Spectrum analyser sees all RF** | Identifies interference from microwave ovens, Bluetooth, radar, etc. |
| **Visual fault locator finds fiber breaks** | Quick and effective but does not measure loss. |
